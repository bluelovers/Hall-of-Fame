# 設定頁 — Setting

- **網址 (URL):** `http://localhost:8085/game/setting`
- **Controller:** `HOF_Controller_Game`

## 功能說明

遊戲設定頁面，提供玩家個人化設定、登出、與帳號管理功能。

### 頁面功能

| 功能 | 操作 | 說明 |
|------|------|------|
| **戰鬥日誌記錄** | checkbox（預設勾選） | 開啟/關閉戰鬥日誌儲存 |
| **停用物品列表 JavaScript** | checkbox | 不使用 JavaScript 顯示物品列表 |
| **顏色設定** | 下拉選單（多個 SampleColor）| 選擇介面顏色主題（所有選項顯示為 SampleColor） |
| **儲存設定** | `modify` 按鈕 | 儲存以上設定變更 |
| **登出** | `logout` 按鈕 | 登出目前帳號 |
| **變更團隊名稱** | 文字輸入框 + `change` 按鈕 | 費用 $300,000，限制 16 字元（全形=2字）|
| **刪除帳號（脱出口）** | 密碼輸入框 + `delete` 按鈕 | 輸入密碼後可刪除所有資料 |

### 設定項目詳情

| 設定 | 預設值 | 說明 |
|------|--------|------|
| 戦闘ログの記録 | 開啟 | 記錄戰鬥過程到遊戲日誌 |
| アイテムリストにJavaScriptを使わない | 關閉 | 以非 JS 方式顯示物品列表 |
| Color | SampleColor | 目前所有顏色的名稱都顯示為 SampleColor（顏色值來自 `HOF/Resource/Color.dat`）|

### 注意事項

- 顏色選項雖都顯示為 SampleColor，實際套用不同顏色樣式
- 變更團隊名稱需要 $300,000 資金
- 刪除帳號為不可逆操作，需輸入正確密碼
- 登出後需要重新輸入帳號密碼
