# 首頁 — Main Page

- **網址 (URL):** `http://localhost:8085/`
- **Controller:** `HOF_Controller_Game`

## 功能說明

遊戲主頁面，登入後顯示玩家的隊伍資訊與角色列表。

### 頁面元素

| 元素 | 說明 | 連結 |
|------|------|------|
| **Top** | 返回首頁 | `/` |
| **Hunt** | 狩獵／戰鬥功能 | `/battle/hunt` |
| **Item** | 物品管理 | `/item` |
| **Town** | 城鎮功能 | `/town` |
| **Setting** | 遊戲設定 | `/game/setting` |
| **Log** | 遊戲日誌 | `/log` |
| **角色頭像** | 角色詳細資訊 | `/char/char?char={hash}` |
| **UpDate** | 更新紀錄 | `/log/update` |
| **Manual** | 操作手冊 | `/manual` |
| **Tutorial** | 教學 | `/manual/tutorial` |
| **GameData** | 遊戲資料一覽 | `/gamedata` |

### 資訊顯示

- 團隊名稱（Team Name）
- 資金（Funds）
- 時間（Time）：當前時間 / 最大時間
