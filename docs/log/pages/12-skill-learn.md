# 技能學習頁 — Skill Learn

- **網址 (URL):** `http://localhost:8085/char/skill_learn?char={角色ID}`
- **進入路徑:** Char Status → SkillLearn 連結
- **Controller:** `HOF_Controller_Char`

## 功能說明

學習新技能，消耗 Skill Point。

### Skill Point 系統

| 項目 | 說明 |
|------|------|
| **獲取方式** | 升級時獲得 1 點 |
| **消耗** | 學習技能消耗 SP（與 SP 欄位不同） |
| **未使用點數** | 顯示於頁面頂部（如「Potential Ability: 1」） |
| **重置** | 無法重置，學習前請確認 |

### 技能學習流程

1. 頁面顯示可學習的技能列表（所有職業 + 無職業限制技能）
2. 每個技能顯示名稱、消耗 SP、效果說明
3. 已學習的技能標記為「■」或灰色不可選
4. 點擊技能名稱前的 Radio Button（部分版本為 Checkbox）
5. 點擊「Learn」按鈕學習

### 技能列表內容

| 欄位 | 說明 |
|------|------|
| **技能圖示** | 技能對應的圖標 |
| **技能名稱** | 技能顯示名稱 |
| **SP 消耗** | 學習此技能需要消耗的技能點數（通常為 1） |
| **狀態** | 未學習（可選）/ 已學習（■ 標記） |

### 技能限制

| 限制類型 | 說明 |
|---------|------|
| **職業限制** | 部分技能僅特定職業可學（如 Bash 限 Warrior） |
| **等級限制** | 部分技能需要角色達到指定等級（如 RagingBlow 需 Lv.6） |
| **前置技能** | 部分技能需要先學習其他技能（技能樹機制） |

### 注意事項

- 建議優先學習職業核心技能
- Warrior 初始已有 Bash（Lv.1 即學會），不需額外學習
- 技能學習後立即可用於戰鬥（需在 Action 頁面設定 Judge）
- Lv1 角色起始 Skill Point = 0（升級後獲得）
