# 戰鬥執行頁 — Battle Execution

- **網址 (URL):** `http://localhost:8085/battle/common?land=gb0`（哥布林區域）
- **前置頁面:** 戰鬥準備頁（需先勾選角色）
- **Controller:** `HOF_Controller_Battle`

## 功能說明

選擇區域與角色後進入戰鬥，執行自動回合制戰鬥，顯示敵我雙方的攻防過程與結果。

### 戰鬥流程

1. **入場** — 雙方角色進入戰場（`enter the Battlefield.`）
2. **回合制自動戰鬥** — 雙方輪流行動：
   - **普通攻擊（Attack）** — 顯示傷害數值與 HP 變化 `(當前HP > 剩餘HP)`
   - **技能攻擊** — 如 `FatalStab` 等技能，傷害通常高於普攻
   - **延遲系統（Delayed）** — `Delayed(0 >>> -50/100)` 表示行動延遲值
3. **勝負判定** — 一方 HP 歸零即結束

### 頁面佈局

| 區域 | 內容 |
|------|------|
| 上方資訊列 | 團隊名稱、資金、時間 |
| 區域資訊 | 區域名稱與等級 |
| 雙方戰力 | Total Lv / Average Lv / Total HP |
| 戰鬥日誌 | 依時間順序顯示所有行動記錄 |
| 底部導航 | UpDate / Manual / Tutorial / GameData / Top |

### 出現怪物（哥布林區域）

| 怪物名稱 | Lv | 招式 |
|----------|-----|------|
| **GoblinAxe** | Lv.1 | 一般攻擊 |
| **GoblinWarrior** | Lv.2 | 一般攻擊、FatalStab（高傷害技能）|

### 操作方式

- `>>` 連結可跳到戰鬥日誌最底部
- 戰鬥結束後自動顯示結果，無需手動操作

## 注意事項

- 戰鬥為自動進行，不可手動下指令
- 延遲值（Delayed）影響行動順序
- 技能傷害通常高於普通攻擊，注意怪物技能
- 戰鬥日誌顯示即時 HP 變化 `(戰鬥前HP > 戰鬥後HP)`
